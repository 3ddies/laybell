# Laybell — 30 Short-Form Scripts (word-for-word)

Paired with the calendar in `GROWTH_CONTENT_AND_OUTREACH.md`. Shoot vertical 9:16, hook on
screen in the first 1–2s, captions always on, end on logo + CTA. Batch 7 at a time.

**One honesty rule:** the **Proof** and **Spotlight** videos must use **real** producers and
**real** numbers. Don't invent payouts or testimonials — fabricated earnings claims get you
banned and burn trust. Until you have a real win, run the Proof slot as a **demo** of the
mechanism ("here's what happens when a beat sells") and swap in the real story the day you
have one. Every Proof/Spotlight script below is marked ⚠️ REAL-DATA.

Legend: **[TH]** talking head · **[SR]** screen recording · **[MON]** beat-making montage · **[FEAT]** creator feature
